# Calico Gravity Forms Styler for Elementor

Style an existing Gravity Form through an Elementor widget, with separate designs per widget and individual field overrides. Elementor Pro is not required.

**Status: 0.1.1 beta / prerelease.** Local WordPress and Elementor integration checks use a Gravity Forms test double. Real Gravity Forms submissions and add-ons still require staging verification. This release does not promise styling access to every third-party form component.

## Features

- Form container, title, description, labels, sub-labels, required indicators and field descriptions.
- Inputs, selects, textareas and placeholders, with hover, focus, disabled and error styling.
- Checkbox/radio controls, sections, HTML fields, upload areas, lists, prices and totals.
- Submit, next, previous, upload and save-and-continue controls.
- Validation summaries, field errors, inline confirmations, progress bars and page steps.
- Typography, colors, borders, radius, padding, margin and shadows where relevant; responsive typography and dimensions.
- Individual field overrides using the Gravity Forms field ID, scoped to the current widget.

Create fields, set columns, and configure logic, feeds, notifications and confirmations in Gravity Forms. This plugin delegates form output to Gravity Forms and supplies styling controls.

## Requirements

WordPress 6.5+, PHP 7.4+, active Elementor using its classic PHP widget system, and a separately installed licensed copy of Gravity Forms 2.7+ with modern markup. Atomic Editor compatibility is unverified. Declared minimum versions are targets; the checked environment is described below.

## Installation and use

1. Install and activate Elementor and Gravity Forms.
2. Download **calico-gravity-forms-styler.zip** from the GitHub Release assets. Use the installable asset rather than the autogenerated Source code archives.
3. In WordPress, choose **Plugins → Add New → Upload Plugin**, upload the ZIP and activate it.
4. Edit a page with Elementor, search for **Calico Gravity Forms Styler**, and add the widget.
5. Select an active Gravity Form in Content, then open Style to customize its parts.
6. For a particular field, add an Individual field overrides row and enter that field's Gravity Forms ID.

Test on staging before production, using test recipients and payment-provider test modes. The Elementor editor displays native form markup; conduct submission tests on the staging frontend.

## Styling limits

Provider-hosted payment inputs and CAPTCHA iframes, browser-native dropdowns and file dialogs cannot be styled freely by widget CSS. The floating datepicker and enhanced-select popups need separate coverage. Survey, quiz, signature and other add-on fields need compatibility testing. Legacy form layouts may not respond to modern spacing controls. Confirmation styling covers inline messages, not redirect pages.

Use different form IDs when embedding multiple forms on one page. Verify saved templates, popups, Theme Builder locations, complex editor previews and field overrides following AJAX validation on staging.

## Verification

User-confirmed functionality was reported on October 19, 2026. The installed version, environment and individual test cases were not specified.

Local checks use PHP 8.3.33, WordPress 6.8.11 and Elementor 4.3.4 with an explicit Gravity Forms test double. They cover widget registration, dependency handling, native-render argument delegation, template asset discovery, field class isolation and Elementor CSS compilation. Browser fixture checks at 1200px and 390px cover scoped computed styles, an individual field override, focus borders, responsive textarea sizing and horizontal overflow.

These checks do not prove real Gravity Forms editor behavior, entries, notifications, AJAX, conditional logic, file uploads, payments or installed add-ons. No production website has been independently verified with this release.

## Updates and recovery

This version does **not** include a GitHub updater. Upgrade manually by uploading a new installable ZIP and choosing to replace the installed plugin. Keep the installed folder `calico-gravity-forms-styler` and main file `calico-gravity-forms-styler.php` unchanged.

Back up before upgrades. If a conflict occurs, deactivate this plugin and reinstall the previous package. Deactivation does not delete Gravity Forms entries or saved Elementor widget settings; the custom widget's output is unavailable until it is active again. Clear an individual style control to return to the inherited form/theme style.

## Build

On Windows with PowerShell and tar.exe, run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

The builder checks version agreement, packages only the production allowlist, compares every ZIP member with source, and writes `dist/vVERSION/calico-gravity-forms-styler.zip` and a SHA256 manifest. Existing packages are never overwritten. The source-upload bundle is not the installable asset.
